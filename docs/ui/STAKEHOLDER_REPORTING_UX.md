# Antigravity Stakeholder Reporting UX

Stakeholders need high-level outcomes and ROI, not technical traces. This document defines the UI patterns for sharing results with non-operators.

## 1. The "Outcome Report" (View-only)
- **Flattened Artifact**: A simplified, high-fidelity view of the final generated document or data.
- **Executive Summary Widget**: A generated 3-sentence summary of the task's success and impact.
- **Success Scorecard**: A clear visual grid showing which original requirements were met.

## 2. Public Transparency Portal
- **Mission Pulse**: A read-only dashboard for stakeholders to see the progress of high-priority organizational goals.
- **Jargon-free Trace**: A simplified version of the Decision Trace that replaces technical terms with business outcomes (e.g., "Invoking analyzer" -> "Evaluating market trends").

## 3. Sharing & Presentation
- **Permanent Links**: Secure, password-protected URLs for sharing specific artifacts.
- **Presentation Mode**: A full-screen, slide-like view for walking through task outcomes during a meeting.
- **Annotated Walkthroughs**: Pre-recorded or live agent-led summaries of the report highlights.

## 4. Feedback for Stakeholders
- **Strategic Rating**: A simplified 3-point rating system (Exceeded/Met/Below Expectations) focused on business value rather than technical quality.
- **ROI Impact Tagging**: Allow stakeholders to "Tag" a task with the specific business win it contributed to.

## 5. Visual Aesthetics
- **High-Fidelity PDF Exports**: Ensuring generated reports use the organization's typography and color palette for external sharing.
- **Branded Themes**: Automatic application of corporate branding to stakeholder-facing portals.
