# Antigravity Subscription & Usage UX

This document defines how Antigravity communicates value, billing, and resource limits to users and administrators.

## 1. Value Realization Dashboard
- **ROI Metric**: A prominent "Total Value Generated" counter (e.g., "120 Hours Saved").
- **Efficiency Benchmarks**: Compare current usage to "Manual Worker Equivalents."
- **Task Success Heatmap**: Visualization showing which types of tasks are most successful and providing the most value.

## 2. Resource Limit Visibility
- **The Progress Gauges**: Real-time status of current usage against plan limits:
  - **Concurrent Tasks**: "3 of 5 active."
  - **Token Budget**: "75% of monthly allowance used."
  - **Storage**: "1.2GB of 10GB used."
- **Threshold Alerts**: Non-intrusive banners when usage exceeds 80% or 90% of a limit.

## 3. Cost Control & Billing
- **Current Spend**: A high-density view of accumulated costs for the current billing cycle.
- **Project Attribution**: Allow users to tag tasks with "Project Codes" to see cost-per-project.
- **Invoicing**: A list of past invoices with one-click download.

## 4. Upgrade & Expansion Paths
- **"Unlock Feature" Badges**: Muted indicators for features available in higher tiers (e.g., "Multi-agent swarm available in Pro").
- **Seamless Upgrade Flow**: An inline "Upgrade Now" button that opens a comparison matrix and credit card entry within the dashboard.

## 5. Usage Forecasting
- **The "Runway" View**: A predictive line chart showing when the user is expected to hit their limits based on current trends.
- **Optimization Suggestions**: The agent proactively suggests ways to reduce cost (e.g., "I've noticed your 'Research' tasks use expensive models; should I try a smaller model first?").
