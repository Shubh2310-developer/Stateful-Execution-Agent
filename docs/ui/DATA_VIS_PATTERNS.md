# Antigravity Data Visualization Patterns

Antigravity transforms raw data into insights. This document defines the standards for the charts and graphs generated by the agent or used in the analytics views.

## 1. Visual Style
- **Minimalist Aesthetics**: Use the [Plus Jakarta Sans](./DESIGN_SYSTEM.md) font. No unnecessary grid lines or 3D effects.
- **Color Palettes**: Use the [Design Tokens](./DESIGN_TOKENS.md) for data series.
  - *Primary Series*: Blue (`#3B82F6`)
  - *Comparison Series*: Slate (`#64748B`)
  - *Success/Emerald*: Green (`#10B981`)
  - *Failure/Error*: Red (`#EF4444`)

## 2. Chart Selection Rules
The agent follows these rules when selecting a visualization for an artifact:

| Data Goal | Recommended Chart |
| :--- | :--- |
| **Trend Over Time** | Line Chart (smooth interpolation) |
| **Categorical Comparison** | Bar Chart (horizontal for many categories) |
| **Part-to-Whole** | Donut Chart (max 5 slices) or Stacked Bar |
| **Process/Flow** | Sankey Diagram or Flowchart |
| **Correlations** | Scatter Plot with Trend Line |

## 3. Interaction & Accessibility
- **Hover Tooltips**: High-contrast labels showing exact values and percentages.
- **Keyboard Access**: Users should be able to `Tab` through data points; the tooltip should remain visible on focus.
- **Colorblind Safe**: Use varying line patterns (solid, dashed, dotted) or markers (circles, squares, triangles) when more than 3 series are present.
- **Downloadable Data**: Every chart should have a "View as Table" or "Download CSV" option.

## 4. In-App Performance Metrics
For analytics dashboards:
- **Real-time Updates**: Charts should animate smoothly when new data points arrive.
- **Interactive Legends**: Clicking a series name in the legend should toggle its visibility on the chart.
- **Time Range Pickers**: Standard controls for switching between 24h, 7d, 30d, and custom ranges.

## 5. Multi-modal Visualization
- **AI-Generated Charts**: The agent can describe a chart in JSON format, which the UI then renders natively using [Recharts](https://recharts.org/) or [D3.js].
- **Embedding**: Generated charts should be easily embeddable into the final PDF or Markdown artifacts.
