# Antigravity Task Template UX Patterns

Task Templates allow users to quickly launch common mission plans. This document defines the patterns for template discovery and creation.

## 1. Template Gallery
- **Inspiration Grid**: A set of cards representing common use cases (e.g., "Weekly Performance Audit," "Competitive Research Pulse").
- **ROI Estimates**: Each template shows the "Estimated Time Saved" based on historical organizational data.
- **Capability Badges**: Indicators of which tools the template requires.

## 2. Template Customization
- **Parameter Forms**: A simple, wizard-style UI for entering required variables (e.g., "Select the Date Range," "Upload the Data File").
- **Plan Preview**: A non-interactive version of the [State Visualization](./STATE_VISUALIZATION.md) showing the steps the template will generate.

## 3. Template Creation (The "Save As" Pattern)
- **Post-task Optimization**: After a successful custom mission, the agent asks: "That worked well! Would you like to save this plan as a template for your team?"
- **Blueprint Editor**: A UI to "Generalize" a successful plan by replacing specific values with dynamic variables.

## 4. Team Templates
- **Pinned Blueprints**: Admins can pin "Verified" templates to the top of the dashboard for standardized work.
- **Usage Leaderboard**: See which templates are the most popular and providing the most value to the team.

## 5. Versioning for Templates
- **Blueprint Updates**: When an SOP or tool changes, the associated template can be updated across the organization with a single click.
- **History of Intent**: Track how a template has evolved over time based on feedback from multiple users.
