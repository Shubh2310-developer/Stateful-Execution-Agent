# Antigravity Keyboard Shortcut Reference

Efficiency is a core value for Antigravity operators. This document lists the standard keyboard shortcuts for the interface.

## 1. Global Navigation
| Shortcut | Action |
| :--- | :--- |
| `Cmd + K` / `Ctrl + K` | Open Global [Command Palette](./COMMAND_PALETTE.md) |
| `G + D` | Go to Dashboard |
| `G + T` | Go to Task History |
| `G + M` | Go to Memory Management |
| `G + S` | Go to Settings |

## 2. Task Management (Active Task)
| Shortcut | Action |
| :--- | :--- |
| `Cmd + Enter` | Create / Execute Task |
| `Space` | Pause / Resume current task |
| `Esc` | Cancel current task or close modal |
| `Cmd + R` | Restart current step |
| `Cmd + Shift + B` | Open State Visualization (Graph) |

## 3. Mission Control (Workplace)
| Shortcut | Action |
| :--- | :--- |
| `[` | Toggle Sidebar visibility |
| `]` | Toggle Trace Panel visibility |
| `Cmd + F` | Search within current Artifact or Trace |
| `Alt + Up/Down` | Move between State Versions (Time Travel) |

## 4. Decision Trace & Feedback
| Shortcut | Action |
| :--- | :--- |
| `Cmd + J` | Focus the Refinement Input |
| `Option + A` | Approve current checkpoint |
| `Option + D` | Deny current checkpoint |
| `1 - 5` | Assign star rating to completed task (when focused) |

## 5. Accessibility Note
All shortcuts must be configurable in the User Settings. If a shortcut conflicts with a screen reader command, the UI should provide an alternative or allow for rebinding.
