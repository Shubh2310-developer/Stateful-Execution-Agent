# Antigravity Help & Documentation Center UI

The Help Center is a context-aware resource integrated directly into the Antigravity workspace.

## 1. Contextual "What's This?"
- **Tooltips**: High-contrast, minimal tooltips for all specialized UI terms (linked to the [Glossary](./GLOSSARY.md)).
- **Inline Guides**: "Mini-docs" that appear next to complex features (like the State Graph) upon first use.
- **Smart Search**: A search bar that prioritizes documentation relevant to the *current* view or task.

## 2. Integrated Support Agent
- **The "Helper" Persona**: A specialized agent whose only goal is to assist the user in navigating the UI.
- **Proactive Help**: "I noticed you're having trouble connecting to MongoDB. Here is a 3-step guide to fix it."
- **Task-based Tutorials**: "Walk me through creating my first investor update."

## 3. Interactive Component Playground
- **UI Sandbox**: A section where users can interact with UI components (buttons, charts, cards) to understand how they work before using them in a mission.
- **Video Snippets**: Short (< 30s) looping GIFs or videos demonstrating complex gestures or workflows.

## 4. Documentation Hierarchy
- **Level 1: Quick-starts**: 2-minute guides for immediate value.
- **Level 2: Module Deep-dives**: Detailed technical specs for each part of the system.
- **Level 3: API & SDK**: The [API Documentation](./API_DOCS_UX.md) for developers.

## 5. Community Knowledge Base
- **User Forums**: Integrated discussion threads where operators share "Mission Tips."
- **Voted Solutions**: Mark specific user-contributed tips as "Expert Verified."
- **Changelog Pulse**: A high-level, visual feed of new features and system improvements.
