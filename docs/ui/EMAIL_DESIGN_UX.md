# Antigravity Email Design Guidelines

Email notifications in Antigravity are functional, branded, and optimized for both high-level summaries and detailed audits.

## 1. Visual Standards
- **Typography**: Clean sans-serif stack (`Inter`, `Helvetica`, `Arial`).
- **Colors**: Primary Blue (`#3B82F6`) for headers and CTAs; Slate for body text.
- **Branding**: The Antigravity logo in the header and a "Generated by Antigravity" footer.

## 2. Notification Types

### A. Task Completion
- **Hero Section**: Large "Goal Achieved" title.
- **Summary**: A 3-sentence summary of the outcome.
- **Attachments**: Link to the generated PDF/Artifact with a one-click download button.
- **Learning**: A small section showing "What the agent learned" during this task.

### B. Action Required (Checkpoint)
- **High-Visibility Banner**: Amber background with an "Attention Required" icon.
- **The Ask**: A clear, concise question or decision request.
- **Quick Action**: Deep links to "Approve" or "Modify" in the web UI.

### C. Weekly ROI Digest
- **Metrics Grid**: ROI stats (Time saved, Cost, Goals met).
- **Success Highlights**: Carousel of the most successful tasks from the previous week.
- **System Health**: A brief "Operational Status" summary.

## 3. Technical Requirements
- **Responsive**: Fluid layouts that work perfectly on mobile email clients.
- **Dark Mode**: Support for `prefers-color-scheme: dark` using media queries.
- **Accessibility**: Correct semantic HTML, alt text for images, and high-contrast text.

## 4. Transactional Emails
- **Auth**: OTP (One-Time Password) or Login magic link emails.
- **Settings**: Alerts for changed passwords or updated security rules.

## 5. Unsubscribe & Frequency
- **Preference Link**: A direct link to the [Notification Settings](./NOTIFICATIONS.md) in the UI.
- **Frequency Control**: Allow users to switch from "Real-time" to "Daily Digest" for non-critical updates.
