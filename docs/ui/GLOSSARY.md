# Antigravity UI Glossary

This glossary defines specialized terms used within the Antigravity UI and its documentation to ensure consistency across the design and development lifecycle.

| Term | Definition | UI Representation |
| :--- | :--- | :--- |
| **Artifact** | A tangible output generated by the agent (e.g., PDF, JSON data, Markdown doc). | `FileText` icon card with download options. |
| **Decision Trace** | The real-time, append-only stream of the agent's reasoning and tool usage. | Vertical feed in the right-side "Trace Panel." |
| **Glass Box** | The design principle of providing full transparency into autonomous AI processes. | Real-time reasoning logs and confidence scores. |
| **Goal** | The high-level user request that initiates a task (e.g., "Analyze Q1 growth"). | Hero title in the Task Execution view. |
| **Memory Cluster** | A semantic grouping of learned facts or patterns in long-term memory. | Visual nodes or grouped cards in the Memory view. |
| **Mission Control** | The primary view for monitoring a specific active task. | The main task execution layout. |
| **Operator** | The human user overseeing and directing the agent's work. | References to "You" or "User" in the UI. |
| **Plan** | The structured sequence of atomic steps generated by the Planner module. | Stepper or tree visualization. |
| **Progressive Disclosure** | Moving from high-level summaries to deep technical details based on user intent. | Expandable cards and "View More" links. |
| **State Snapshot** | A versioned capture of the entire application state at a point in time. | "Restore" points in the history view. |
| **Step** | An atomic, executable unit of work within a larger plan. | Individual items in the `StepIndicator`. |
| **Success Criteria** | Measurable requirements defined during the planning phase. | Checklist items with pass/fail indicators. |
| **Vibecoding** | Aesthetic-first design without functional purpose. | **Anti-pattern**: We avoid this in favor of functional utility. |
