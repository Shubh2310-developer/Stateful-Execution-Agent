# Antigravity UI Onboarding Experience

The onboarding flow for Antigravity is designed to transition users from "AI curiosity" to "Operational efficiency" within minutes. In 2026, onboarding is not a series of static tooltips but an interactive, agent-led introduction.

## 1. The "Zero State" Experience

When a user first authenticates, they are met with a clean, high-impact "Mission Control" interface.

- **The Welcome Agent**: Instead of a generic modal, the agent initiates a "Introduction Task."
- **Visuals**: A minimalist hero section with the Antigravity logo and a clear value proposition: "Your persistent knowledge worker is ready."
- **Initial Setup Gauge**: A small progress indicator showing the steps to "Full Operational Readiness" (e.g., Connect LLM, Connect Data, Set First Goal).

## 2. Interactive Agent-Led Walkthrough

We avoid the "Click Next" pattern. Instead, the onboarding *is* a task.

- **The Sample Goal**: The agent suggests a simple, safe task to demonstrate its power (e.g., "Summarize the project README and set a mission plan").
- **Live Explanation**: As the agent executes this first task, it uses the **Decision Trace** to explain its actions: "I'm reading your README now to understand your project structure."
- **Permission Discovery**: The agent proactively asks to connect tools: "I see you have a Slack integration available. Should I connect it so I can send you updates?"

## 3. The "Trust Building" Checkpoints

Onboarding must emphasize the "Glass Box" principle immediately.

- **First Intervention**: The agent intentionally pauses during the first task and asks for a preference: "Do you prefer your summaries in bullet points or paragraphs?"
- **Memory Visualization**: After the user responds, the UI highlights the **Memory** tab: "Learned: You prefer bulleted summaries. I'll remember this for all future tasks."

## 4. Documentation & Resource Hub

- **Embedded Quick-starts**: Context-aware documentation snippets available directly in the sidebar during the first 48 hours of usage.
- **Template Gallery**: A library of "Proven Mission Plans" for common industries (SaaS, Fintech, Healthcare) to inspire the first "Real" goal.
- **Support Chat**: A direct line to technical support, integrated as a specialized "Support Agent" within the standard interface.

## 5. Graduated Feature Release

To prevent cognitive overload, advanced features are introduced as the user gains experience.

- **Day 1**: Goal creation, basic monitoring, and artifact export.
- **Day 3**: Introduction to the **State Visualization** graph and **Memory** management.
- **Day 7**: Advanced **Command Palette** shortcuts and **Multi-agent** coordination.

## 6. Success Milestones

- **First Task Completed**: A celebratory (but professional) visual confirmation.
- **First Memory Saved**: An indicator showing how much time will be saved in the future thanks to this learned preference.
- **Integration Connected**: A "System Expanded" badge to signal increased agent capability.
