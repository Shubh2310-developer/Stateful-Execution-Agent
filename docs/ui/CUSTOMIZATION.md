# Antigravity Customization & Theming

To ensure Antigravity fits seamlessly into various enterprise environments, we provide robust customization and whitelabeling capabilities.

## 1. Theme Engine
- **CSS Variables**: All primary, secondary, and background colors are controlled via CSS variables (e.g., `--color-primary`).
- **Mode Switching**: Standard support for Light, Dark, and "System Default" modes.
- **Color Palettes**: A set of pre-defined, professional color schemes (e.g., "Emerald Insight," "Midnight Slate," "Slate & Steel").

## 2. Whitelabeling (Enterprise)
- **Custom Branding**: Upload organizational logos for the sidebar, login screen, and generated artifacts.
- **Custom Domains**: Support for hosting the UI on a sub-domain (e.g., `agent.acme.corp`).
- **Artifact Templates**: Custom CSS/HTML templates for generated PDFs and reports to match the company's brand guidelines.

## 3. Layout Customization
- **Density Toggles**: "Comfortable" vs. "Compact" modes for managing information density.
- **Panel Arrangement**: Allow users to swap the placement of the Trace and Workplace panels (e.g., Trace on the left).
- **Collapsible Elements**: Persistent state for sidebar and panel visibility (remembering what the user has collapsed).

## 4. Tool & Integration Branding
- **Custom Icons**: Allow users to upload custom icons for their internal, proprietary tool integrations.
- **Contextual Labels**: Rename standard UI sections to match internal terminology (e.g., "Task History" -> "Operational Audit").

## 5. Dashboard Configuration
- **Widget-based Dashboard**: A drag-and-drop interface for choosing which analytics widgets (ROI, Cost, Success Rate) appear on the main landing page.
- **Saved Views**: Allow users to save their specific layout and filter configurations for quick access.
