# Antigravity UI Components

This document defines the reusable UI components for the Antigravity interface, following the Flat Design system.

## Atomic Components

### Buttons
- **Primary**: `bg-blue-600 text-white rounded-lg px-4 py-2 font-medium hover:bg-blue-700 transition-colors cursor-pointer`
- **Secondary**: `bg-white border border-slate-200 text-slate-900 rounded-lg px-4 py-2 font-medium hover:bg-slate-50 transition-colors cursor-pointer`
- **Ghost**: `text-slate-500 hover:text-slate-900 px-2 py-1 rounded transition-colors cursor-pointer`

### Status Pills
- **Success**: `bg-emerald-50 text-emerald-700 border border-emerald-100 px-2 py-0.5 rounded-full text-xs font-semibold`
- **Pending**: `bg-indigo-50 text-indigo-700 border border-indigo-100 px-2 py-0.5 rounded-full text-xs font-semibold`
- **Running**: `bg-blue-50 text-blue-700 border border-blue-100 px-2 py-0.5 rounded-full text-xs font-semibold animate-pulse`
- **Error**: `bg-red-50 text-red-700 border border-red-100 px-2 py-0.5 rounded-full text-xs font-semibold`

### Icons
- Use **Lucide React** or **Heroicons** (SVG).
- Default size: `w-5 h-5`.
- Color: Inherit or `text-slate-400` for decorative icons.

## Molecular Components

### Task Card
A card representing a high-level goal and its current progress.
- **Structure**:
  - Header: Goal title + Status Pill.
  - Body: Progress percentage + Progress bar.
  - Footer: Last activity timestamp + "View Trace" button.
- **Style**: `bg-white border border-slate-200 rounded-xl p-6 shadow-sm hover:border-blue-300 transition-all cursor-pointer`

### Step Indicator
A vertical or horizontal list showing the execution plan progress.
- **Structure**:
  - Icon (Check/Running/Pending).
  - Label: Step action (e.g., "Analyze Metrics").
  - Description: Short detail on what the step is doing.
- **Style**: Vertical connector lines for dependency visualization.

### Decision Trace Entry
A specialized component for the "Glass Box" visibility.
- **Structure**:
  - Timestamp (muted).
  - Decision Point title.
  - Reasoning snippet (expandable).
  - Action taken + Confidence Score badge.
- **Style**: `border-l-2 border-slate-200 pl-4 py-3 space-y-2`

### Artifact Preview
A compact card for files/documents generated by the agent.
- **Structure**:
  - File icon (PDF/MD/JSON).
  - Filename + Size.
  - Download/Open buttons.
- **Style**: `bg-slate-50 border border-slate-200 rounded-lg p-3 flex items-center justify-between`
