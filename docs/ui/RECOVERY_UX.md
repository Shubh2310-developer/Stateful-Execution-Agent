# Antigravity Recovery & Resumption UX

Stateful execution allows for robust recovery from interruptions and errors. This document defines the UI patterns for resuming tasks and recovering from failures.

## 1. The Resumption Context
When a user returns to a paused or interrupted task, the UI must provide immediate situational awareness.
- **Resumption Banner**: A high-visibility banner at the top of the workplace: "Task Paused at Step 3. Ready to Resume."
- **"Where We Left Off" Summary**: A 2-sentence summary generated by the agent: "I've completed the data gathering and analysis. I am ready to begin drafting the narrative section."
- **Contextual Breadcrumbs**: Highlighting the last successful Decision Trace entry and the current state of any artifacts-in-progress.

## 2. Recovery from Critical Errors
- **Error Breakdown**: Clearly distinguish between "Agent Error" (logic failure) and "System Error" (API/Infra failure).
- **Automated Solutions**: Present 1-3 "Recovery Paths":
  - `[Retry]` - Attempt the step again with the same parameters.
  - `[Modify & Retry]` - Edit the step inputs before re-running.
  - `[Skip Step]` - Mark the step as failed/skipped and move to the next.
- **Impact Warning**: If skipping a step will break subsequent dependencies, the UI must flag this clearly.

## 3. Resumption with New Context
Sometimes a user returns with new information that should change the task's path.
- **"Resume with Feedback"**: A primary input area that allows the user to say: "I'm back, actually use this new data file for the remaining steps."
- **Re-planning Trigger**: If the new feedback significantly changes the goal, the agent should show a "Re-planning Required" state and present a new version of the execution plan.

## 4. Persistent Workspace State
The UI itself should "Recover" its exact layout:
- **Panel State**: Restore which panels were expanded/collapsed.
- **Scroll Position**: Maintain the user's last position in the Decision Trace.
- **Draft Feedback**: If the user was typing a correction when they were interrupted, restore the draft text.

## 5. Visual Safety Net
- **Checkpoint Snapshots**: Automatically create a [State Version](./VERSIONING_UX.md) before every resumption to ensure the user can always undo a resumption if it goes wrong.
- **Success Confirmation**: Once a task successfully resumes and completes its first post-recovery step, show a subtle "Recovered Successfully" confirmation.
