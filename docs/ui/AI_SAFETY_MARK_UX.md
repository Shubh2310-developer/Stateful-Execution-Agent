# Antigravity AI Safety Holographic Mark

To distinguish between human and AI-generated content, Antigravity embeds a "Holographic Mark" into every UI surface and artifact.

## 1. The "Livemark" Indicator
- **Visual**: A subtle, shimmering border or watermark that appears on any text or chart generated by the agent.
- **Dynamic**: The mark "pulses" when the underlying data is being streamed or modified by an active reasoning process.

## 2. Artifact Provenance Badge
- **Location**: Top-right of every artifact preview.
- **Function**: Click to see the "Lineage" (which agent, which model, which state version).
- **Authenticity Proof**: A cryptographic signature that confirms the artifact was indeed generated by the Antigravity system and hasn't been tampered with.

## 3. Truth-level Visualization
- **Source Strength**: Color-coding the Holographic Mark based on the quality of sources used.
  - *Emerald Mark*: Primary, verified sources only.
  - *Slate Mark*: Mixed sources.
  - *Amber Mark*: Unverified or potentially biased sources.

## 4. Visual Content Integrity
- **Image/Chart Protection**: A subtle, non-distracting digital watermark embedded into the pixels of generated images to prevent "Deepfake" misuse or misattribution.
- **Verification Tool**: A "Check Authenticity" web surface where external stakeholders can upload a file to see its Antigravity-signed history.

## 5. Identity Verification
- **User-Agent Handshake**: A visual pattern that appears when a user approves a step, showing the "Joint Signature" of the Human-Agent partnership.
- **Agent Self-Correction Mark**: A specialized marker when an agent revises its own previous output, maintaining a clear record of the "Evolution of Truth."
